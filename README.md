# Loon

个人自用的 Loon 配置、插件与脚本，仅供本人学习与测试使用。

本仓库不提供任何支持，内容可能随时变动或失效，请勿订阅或转载。

感谢各位上游作者的付出，相关插件与脚本内已注明来源，图标来源与许可见 [Icons/README.md](Icons/README.md)。

[插件索引](Docs/Plugins.md) · [Pica 插件与安装说明](Docs/Pica/README.md)

`Plugins/` 只放订阅文件，同一项目的多个插件放子目录；说明统一放 `Docs/`。运行脚本与图标分别在 `Scripts/`、`Icons/`。Pica 已按 App、网页和临时诊断整理，其他既有订阅路径保持不变。
