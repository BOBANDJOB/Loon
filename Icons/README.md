# Icons

- `app/`：App 图标，供插件 `#!icon` 使用，也收录了部分常用 App 的本地副本
- `plugin/`：另一套风格的插件图标
- `area/`、`common/`：地区与策略组图标
- `ai/`：AI 生成的原创图标，用 tools/icon_gen.py 生成
- `icons-all.json`：图标订阅，包含以上本地图标和各上游图标库的链接，已去重
